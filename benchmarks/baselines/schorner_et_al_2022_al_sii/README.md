# Otter states for the Schörner et al. (2022) aluminium comparison

These four archives were generated by the complete gallery program
`benchmarks/examples/plot_schorner_et_al_2022_al_sii.py` with Otter 0.2.2.
They contain project-generated equilibrium PA-HNC structure factors using
both LDA-PW92 (`lda_pw`) and PBE (`pbe`) for:

- Al, `rho = 4.712 g/cc`, `Te = Ti = 1 eV`;
- Al, `rho = 8.1 g/cc`, `Te = Ti = 5 eV`.

Both states pass the full-AA stage-2, external-AA, threshold-state, HNC
fixed-point, and real/reciprocal transform-closure gates. The retained arrays
are pickle-free and cover `k <= 20 Bohr^-1`.

The archives retain the Libxc 7.0.0 provider version, exact component IDs,
references, and DOIs. LDA means `lda_x + lda_c_pw`; PBE means
`gga_x_pbe + gga_c_pbe` and uses Otter's documented finite-core GGA
regularization.

The literature data are stored separately under
`benchmarks/reference_data/schorner_et_al_2022_al_sii`. Its raw 1 eV ordinate
is corrected by `+1.5` only when loaded; the original CSV is never rewritten.
The reference package carries article attribution and license status
`NOASSERTION`. These Otter-generated baseline archives are project output.

With `USE_PRECOMPUTED_DATA = True`, the gallery validates the checksums below
before plotting. Set it to `False` to calculate fresh candidates under
`benchmarks/outputs/schorner_et_al_2022_al_sii/gallery_recomputed` without
silently replacing these accepted files.
