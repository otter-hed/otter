# Otter ion-structure reference results

These seven archives were generated by Otter at the revision and with
the complete configuration recorded in `manifest.json`.  They are compact,
pure-numeric NPZ files and load with `allow_pickle=False`.

All seven Otter states and the Be VMHNC curve use the September 2026
recalculation. Be MD retains the earlier potential and is explicitly flagged
`md_is_historical=True`; matching with the new potential is not verified.

All seven states now use the September 9 default-input campaign. Their
recorded workflow configurations are retained per state, with the producing
source hashes in `../validation_20260909.json`. The raw-charge acceptance
limit is unchanged. `provenance_recovery.json` is evidence for an earlier
campaign only, not the source of the current seven states.

Run the fast, offline comparison with:

```bash
python benchmarks/runners/plot_ion_structure_library.py
```

To stage an expensive fresh calculation without changing these accepted
files:

```bash
python benchmarks/runners/regenerate_ion_structure_library.py
```

For the Wünsch Be state the producer also evaluates Rosenfeld--Ashcroft VMHNC
and a 2048-ion, same-potential LAMMPS NVT-to-NVE calculation.  The shared
single-/multi-species driver is `tools/otter_lammps_md.py`; generated LAMMPS
inputs, tables, logs, RDF blocks, trajectories, uncertainties, and hashes are
kept under the candidate output's `md_work` directory.  Edit
`STATE_GROUPS_TO_RUN = ("be_wunsch",)` in the producer to recompute only this
case.  Accepted baselines are never overwritten by that script.

The generated literature overlays are validation aids, not a claim that every
reference method is expected to coincide with Otter.  See the adjacent
reference-data package for citation, units, exclusions, and the public-release
source and reuse notice.
