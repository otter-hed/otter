Scientific benchmark gallery
============================

This gallery contains fixed-state validation studies and comparisons with
published data. Run a page's Python source to calculate its electronic and
ionic states and generate the plots. No precomputed Otter NPZ is required.
Pages containing MD require LAMMPS and MPI. Documentation builds display
recorded figures and terminal output; they do not launch scientific calculations.

The scripts are already included in the complete source checkout. For setup
and the Python, notebook and ZIP download options, see
:doc:`/user_guide/reproducing_galleries`.

These pages are separate from the capability-oriented :doc:`example gallery
</gen_examples/index>`.  They test documented scientific configurations;
they are not templates for silently changing a benchmark state.
