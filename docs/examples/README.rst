Example gallery
===============

Runnable examples cover average-atom electronic structure, QM/TF and
IS/SC comparisons, one- and multicomponent QOZ/HNC, LFC sensitivity,
and ionization and pressure ionization.

Each page places figures and terminal diagnostics before its downloadable
Python source. Running that source calculates from physical inputs by default;
no bundled NPZ is required. Each figure is exported as PNG and vector PDF.
Documentation builds display recorded figures and output without starting
the scientific calculations. Published-data comparisons live in the separate
:doc:`scientific benchmark gallery </benchmarks/gen_benchmarks/index>`.

Run the included scripts from a complete source checkout. The optional Python,
notebook and ZIP downloads are explained in
:doc:`/user_guide/reproducing_galleries`.
